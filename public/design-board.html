Sign-Off #1: Direction

Design Direction

Both themes ship. Users toggle between light and dark mode. Each has its own personality — not just inverted colors.

Light Mode (Default)

☼ "Festival Campfire"

Warm, inviting, earthy. Like sitting around a fire at Shangri-La. Cream backgrounds, forest greens, amber accents. The default for newcomers discovering WookieFoot.

  • Light/warm backgrounds (cream, canvas)
  • Forest green + amber gold as primary colors
  • Organic textures, sacred geometry patterns
  • Approachable, welcoming, community feel
  • Default for first-time visitors
Dark Mode

☾ "Sacred Night"

Deep, mystical, cosmic. Like the night sky at a festival. Dark earth backgrounds with gold and teal accents. An immersive reading experience for lyrics.

  • Earth-dark backgrounds (deep brown, charcoal)
  • Gold + teal as primary accents
  • Cosmic textures, subtle mandala overlays
  • Immersive, contemplative reading experience
  • Toggle via sun/moon icon in nav

Both Ship

Light mode is the default (welcoming for new fans). Dark mode is one click away (sun/moon toggle in the nav bar). User preference is saved to localStorage so it persists across visits. Both themes share the same layout and components — only colors and textures change.

Sign-Off #5: Site Structure

Page Structure

Simplified navigation focused on discovery and lyrics.

Pages

  • Home — Hero + band intro, featured video, latest album, community links
  • Albums — Chronological grid with cover art, year, track count
  • Album Detail — Album info + full track list with links
  • Lyrics — Song lyrics with YouTube embed, album navigation, prev/next
  • Community (NEW) — YouTube, Facebook, Shangri-La Fest, Be The Change Charities, Bandcamp, Instagram
  • Search (UPGRADED) — Fuzzy lyrics search — type a fragment, find the song. Highlights matching snippets. Instant, typo-tolerant.

What's Changing

Removing: Spotify links (everywhere), About page (merged into Home), animated particles, glass-morphism, cyberpunk theme, CursorTrail
Adding: Light/dark mode toggle, YouTube embeds on lyrics pages, fuzzy lyrics search (Fuse.js), Community page, Be The Change section, festival content, proper band introduction for new fans

Key Decision: YouTube Integration

25 of ~145 songs have YouTube videos. For those 25, we embed the video player directly on the lyrics page. For the remaining ~120 songs, we show a "Listen on Bandcamp" link instead. Sound right?

How It Works

Architecture: Client-Side Fuzzy Search (Fuse.js)

  • How: All ~145 songs' lyrics loaded client-side (~300KB). Fuse.js performs instant fuzzy matching.
  • Typo tolerance: "forgve it al" still finds "forgive it all" — Fuse.js uses Bitap approximate string matching.
  • Instant: No server round-trip. Results appear as you type. Works offline.
  • Cost: Zero. No API, no database, no external service. Pure client-side JavaScript.
  • Highlighted snippets: Matching phrases highlighted in context so users can verify the match before clicking.

Why Not AI Search?

With only ~145 songs, fuzzy text search handles 95% of use cases — including "I remember something about forgiveness" matching lyrics with "forgive." AI semantic search (embeddings + vector DB) adds cost and complexity for marginal improvement at this scale. Phase 2 idea: An optional "Describe the song" AI button for truly vague queries — but only if basic search falls short.

Key Decision: Search Approach

Fuse.js client-side fuzzy search ships with the redesign. Zero cost, instant results, typo-tolerant. If users consistently can't find what they want, we add AI semantic search later as an enhancement. Sound right?
